02 / Built for product search

Fast where it counts

GPU acceleration is one part of a practical search API — not a requirement for every query.

01 — HYBRID

GPU + CPU routing

Use WebGPU for suitable workloads; fall back cleanly when unavailable or more efficient.

02 — MATCHING

Useful search modes

Fuzzy, substring, token, prefix, typo tolerance, and autocomplete.

03 — TEXT

Unicode-aware

Normalize and match across scripts, including CJK text and emoji.

04 — APP READY

Off-thread & observable

Worker support, cancellation, memory stats, timings, and persistence tools.

05 — ROUTING

Smart dynamic routing

Runs on WebGPU at scale (30k+ items), uFuzzy on CPU when small or unavailable.

06 — TYPING

Zero-stutter keystrokes

Stale searches are dropped mid-flight via AbortSignal and sequence tagging.

07 — SNAPSHOTS

Portable snapshots

Binary encode and restore indexes; one shared GPU device across all of them.

08 — PARITY

Bit-exact parity

Identical normalized scores on GPU and CPU. Zero runtime dependencies.
