Browser-native search · WebGPU + CPU

Find the right thing.

A small, portable search engine for large collections. Run fuzzy and substring search on WebGPU when it helps, with a CPU fallback when it doesn’t.

Try the live benchmark ↗ Explore example apps ↓
Worker-readyUnicode-awareZero runtime dependencies
quick-start.tsTypeScript
import { SearchIndex } from 'webgpu-search';

const index = await SearchIndex.create(files);
const results = await index.search('auth controller', { mode: 'fuzzy' });

// GPU when useful. CPU fallback when needed.

Use the same API in browser apps, Web Workers, Node.js, and SSR. The library selects an execution path based on the device and search workload.
