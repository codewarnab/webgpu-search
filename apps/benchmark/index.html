🔬 Architectural Deep-Dive & Crossover Mechanics 3 Core Takeaways
Expand Details
01

Retained VRAM vs Cold Upload

Uploading 1M rows over PCIe takes ~8–20ms. If data is re-uploaded every keystroke, CPU always wins. But when data is retained in GPU VRAM (loaded once into storage buffers), keystroke search only dispatches a 272-byte uniform, unlocking pure GPU compute speed.

02

The mapAsync() Fixed Latency Floor

WebGPU buffer mapping has an inherent ~1ms to 3ms round-trip overhead. Below 50k items, uFuzzy executes in <1ms on CPU, making CPU 4× faster at small scale. Above 100k–2M items, CPU slows down to 17–160ms+, while GPU compute stays near flat.

03

Candidate Pool Compaction & CPU Ranking

Instead of transferring 2,000,000 rows across PCIe, the compute shader writes up to 8,192 scored candidates into a compact 64 KB buffer using atomic counters. The CPU then sorts candidates by score to return the top 1,000, avoiding PCIe bottlenecks while keeping the UI at 120 FPS.

04

SIMD Warp Divergence Bounding

Variable-length string matching creates warp divergence across SIMD lanes. However, bounding strings to fixed slots (64 bytes) caps thread branch depth to 60 iterations, enabling massive parallel throughput despite divergence.
